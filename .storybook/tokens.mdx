# Design tokens

TypeUI Candy's tokens, read from `src/app/globals.css`, the only file allowed to hold token values
(`npm run tokens` checks the rest). Components use them through Tailwind utilities such as
`bg-card`, `text-heading`, `rounded-control` and `shadow-md`.

## Colours

Colours come in two tiers (`.claude/skills/typeui-design-system/colors.md`).

### Base scales

One numbered scale per hue, lightest first: the app's only hex values, the same in light and dark.
Components never use them directly.

<BaseScales />

### Roles

What components use. Each role points at a base step, and dark mode points it at another.
Swatches follow the toolbar's Theme (dark unless changed); the table lists both steps.
