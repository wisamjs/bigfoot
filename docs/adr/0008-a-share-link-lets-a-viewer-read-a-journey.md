# A Share link lets a Viewer read a Journey

Amends ADR 0001 and ADR 0003. Until now only a signed-in job seeker (through Next.js) or their Access token reached FastAPI's data. A job seeker can now make a Share link so family can follow their search: a Viewer opens `/journey/[id]`, types the Passcode the job seeker chose, and sees their Journey.

FastAPI gets one read-only endpoint for this. It returns a projection built for Viewers: In Progress Applications and Offers, with company, role, applied date, Interview titles, categories and times, and nothing else. Salary, job postings, Prep notes, Interview notes, Outcome notes and Done Applications other than Offers are never selected. We chose a server-side projection over loading the job seeker's full data and hiding fields in React because one rendering bug would then show a Viewer the job seeker's salary; with the projection, the data isn't there to show.

A Viewer proves they know the Passcode once and gets a cookie for that one Share link, separate from Auth.js. Every request checks the Share link again: it must exist, be unexpired, and have the passcode version the cookie was issued for. So stopping a Share link, letting it expire or changing its Passcode cuts Viewers off on their next request, without a session list to clean up. The cookie holds a Viewer token: a JWT FastAPI signs with API_SECRET when the Passcode is right, naming the link and its passcode version, with its own audience so it can't pass for a web token or the other way round. Next.js only stores it, so no second secret is needed. The Passcode is chosen by a person, so it is stored with argon2id, not the SHA-256 that suits a random Access token, and 5 wrong tries lock the Share link for 15 minutes. The link id is random and unguessable, so a Viewer needs both the link and the Passcode.

The costs: FastAPI has a third kind of caller, and the projection must be kept in step with the model (a new private field is private only if it stays out of the projection). Share links expire after 7 days unless renewed, so a forgotten one doesn't stay open.
